# XManager 设计规范

本文是桌面端视觉与交互的单一来源。实现落在 `crates/xmanager-ui/src/theme.rs`（色板、字号、间距）和 `widgets.rs`（控件）。

## 原则

1. **一条主路径**：发现 → 筛选 → 查看 → 加入候选 → 真实删除（自动备份+预演）→ 二次确认。
2. **浏览与删除分离**：内容库不真删；加入候选后仍留在内容库。
3. **状态用文字，不只靠颜色**：危险操作同时用文案、步骤和确认。
4. **即时反馈**：筛选改完立刻更新列表；拉取参数单独标明「下次拉取才生效」。
5. **安全可以慢，挑选不能跳走**：真删要二次确认；挑选时不要把用户带走。

## 字体

| 角色 | 字号 | 行高 | 字重 | 字距意图 | 用途 |
|------|------|------|------|----------|------|
| Caption | 12 | 18 | Regular | +0.2px 略松 | 辅助说明、chip、状态栏、快捷键 |
| Body | 13 | 20 | Regular | 0 | 正文、按钮、列表行 |
| Label | 13 | 20 | Medium | 0 | 区块标题、导航、强调按钮 |
| Title | 16 | 24 | Semibold | −0.2px 略紧 | 页标题 |
| Display | 20 | 28 | Bold | −0.2px | 侧栏产品名 |

行高约为字号的 **1.45–1.50**，保证中西文混排不挤。

字体族：

| 平台 | UI | 等宽（推文 ID / 确认输入） |
|------|----|---------------------------|
| macOS | `.AppleSystemUIFont` | Menlo |
| Windows | Segoe UI | Consolas |
| Linux | Noto Sans CJK SC | DejaVu Sans Mono |

不要在界面里混用第三套字号。新控件从 `theme::type_caption` / `type_body` / `type_label` / `type_title` 里选。

## 间距与控件

4px 节奏：

| Token | px | 用途 |
|-------|----|------|
| `space::XS` | 4 | 紧凑间隙、chip 内边距 |
| `space::SM` | 8 | 控件组、卡片内边距 |
| `space::MD` | 12 | 区块内边距、按钮水平 padding |
| `space::LG` | 16 | 页边距 |
| `space::XL` | 24 | 大区块分隔 |

| Token | px |
|-------|----|
| 按钮高度 | 32 |
| Chip 高度 | 28 |
| 圆角 SM / MD | 4 / 6 |

宽屏导航约 220px；检查器默认 380px，可拖到 220–640px。

## 颜色

浅色为默认。语义色只走 `theme.rs` 的命名 token（`TEXT` / `TEXT_MUTED` / `ACCENT` / `DANGER` / `SUCCESS` / `WARNING`），不要在视图里写死 hex。正文与表面对比至少 4.5:1。

## 交互约定

### 筛选

- 时间、类型、曝光、排序、Top-N、低曝光快捷：**改完立即生效**。
- 抽屉底部「下次拉取」：条数、是否含转发。只影响下一次「拉取并分析」。
- 工具栏 chip 只显示**改变结果的条件**。默认「曝光最低 + 全部类型」不占 chip。
- 「完成」只关抽屉；「清除筛选」恢复无限制并立刻重算。

### 加入安全清理

- 勾选优先；未勾选时，当前查看的一条也可加入。
- **加入后不跳转**，内容库顶部出现横幅：「去安全清理」或「继续挑选」。
- 导航「安全清理」上的数字徽标同步增加。

### 安全清理

主按钮只有一个：**真实删除**（自动备份 + API 预演 + 打开二次确认）。

步骤条表示进度，不是四个必须分别点的按钮：

1. 加入候选
2. 自动备份与预演
3. 二次确认（数量或 `DELETE`）
4. 确认并删除

「另存 CSV/JSON」「只预演不删除」放在「可选」。清空候选需点两次（清空 → 确认清空）。

预演和删除结果优先显示推文摘要，而不是原始 ID。

### 快捷键

| 键 | 作用 |
|----|------|
| `J` / `↓` | 下一条（并从其他页回到内容库） |
| `K` / `↑` | 上一条 |
| 空格 | 勾选当前条 |
| `/` | 打开筛选 |
| `1` `2` `3` | 内容库 / 洞察 / 清理 |
| `Esc` | 关确认 / 错误 / 抽屉 / 窄屏检查器 |

删除确认打开时，除 `Esc` 外不抢键。快捷键写在侧栏、检查器空态和底栏，三处文案保持一致。
