# XManager 完善版页面方案

配套视觉稿：`04-guided-cleanup-workspace.png`

## 核心判断

XManager 不应继续把“筛选、分析、删除”堆在同一个工作台中。更友好的结构是围绕用户真实任务形成三个一级空间：

1. **内容库**：发现、筛选、排序、查看和选择推文。
2. **数据洞察**：理解当前筛选范围的表现分布和排名。
3. **安全清理**：集中复核候选内容，完成备份、预演和真实删除。

左侧区域因此成为真正的导航，而不是装饰图标或另一组筛选条件。

## 产品原则

- 浏览与删除分离，避免用户在查看列表时误触危险操作。
- 导航只承载真实可用的页面，不增加空白的设置、历史或任务页面。
- 筛选按需展开，常驻区域只显示筛选入口和已生效条件。
- 区分“当前筛选结果”“当前勾选项”“安全清理候选项”。
- 页面切换后保留筛选、排序、滚动位置、当前查看推文和清理候选项。
- 备份、预演和真实删除必须绑定同一批候选内容。
- 状态不能只依赖颜色表达，危险操作必须同时使用文字和明确步骤。

## 全局框架

宽屏下使用约 220px 的固定导航栏：

- **内容库**：主入口。
- **数据洞察**：使用当前内容库筛选范围计算统计和排名。
- **安全清理**：显示候选数量徽标。
- 底部显示同步条数、最后同步时间、凭证状态和刷新入口。

不再保留永久占位的密集筛选侧栏。筛选改成内容区中的抽屉。

## 内容库

### 页面头部

- 标题：内容库。
- 说明：发现、复核并整理低表现推文。
- 次要操作：导出当前结果。
- 主要操作：拉取并分析。

### 条件控制区

- 筛选入口及生效条件数量。
- 排序指标、升降序和 Top-N。
- 下一行显示可单独移除的生效条件标签。
- 修改条件后明确区分“未应用修改”和“已生效条件”。

### 内容区

- 左侧约 68% 为虚拟化推文列表。
- 右侧约 32% 为推文检查器。
- 点击行只负责查看；复选框只负责选择。
- 检查器支持上一条、下一条、完整正文、发布时间、类型和核心指标。
- 已选内容通过底部固定栏加入安全清理，不在内容库中直接删除。

### 必备状态

- 尚未同步：解释用途并提供拉取按钮。
- 首次加载：骨架状态。
- 刷新中：保留旧数据并显示更新提示。
- 无匹配结果：显示当前条件和清除筛选入口。
- 请求失败：保留最后可用数据并提供重试。

## 数据洞察

- 页头明确说明统计范围来自内容库的当前筛选。
- 展示已有汇总指标、曝光分布和 Top-N 排名。
- 点击直方图区间或排名项，应用相应条件并返回内容库。
- 仅改变图表展示方式时，不得修改安全清理候选项。
- 支持导出当前分析范围。

## 安全清理

采用四步流程：

1. **复核候选**：查看、移除候选项，允许返回内容库继续添加。
2. **创建备份**：对候选快照导出 CSV 或 JSON，记录数量、路径和完成状态。
3. **预演删除**：对同一候选快照执行 dry-run，区分可删除、已不存在和失败项目。
4. **真实删除**：备份和预演均匹配当前候选版本后才可启用。

候选项任何变化都会产生新版本，并立刻让旧备份凭据和预演结果失效。真实删除前再次显示准确数量和不可恢复提示，并要求输入数量或 `DELETE` 完成二次确认。

执行期间冻结候选项修改并防止重复提交。部分失败时，只保留失败项用于再次处理，已经成功的内容不会重复删除。

## 响应式规则

- **≥1200px**：完整导航栏，内容列表和右侧检查器同时显示。
- **800–1199px**：导航收窄为带提示的图标栏；筛选和检查器使用抽屉。
- **<800px**：导航、筛选和详情均使用全高覆盖层；清理步骤纵向排列。
- 窄屏优先把表格转换为带字段标签的行卡片，避免依赖横向滚动。

## GPUI 实现边界

- 增加页面枚举：`Library | Insights | Cleanup`。
- 集中维护响应式 `LayoutMode`，避免组件各自判断宽度。
- 把内容库查询、当前查看推文和安全清理会话拆成三类状态。
- 安全清理会话维护候选 ID、版本号、快照指纹、备份凭据和预演凭据。
- 现有抓取、筛选、统计、导出和删除逻辑继续作为唯一业务实现，视图只负责派发操作。
- 安全状态机必须能够脱离 GPUI 渲染单独测试。

## 验收标准

- 左侧只有内容库、数据洞察和安全清理三个真实目的地。
- 原有能力都有明确归属，没有重复入口或装饰页面。
- 用户可完整完成“发现 → 筛选 → 查看 → 加入候选 → 备份 → 预演 → 删除”。
- 页面切换不丢失筛选范围或清理候选项。
- 真实删除必须同时具备匹配当前候选版本的备份和预演凭据。
- 候选项变化后安全凭据立即失效。
- 空状态、加载、刷新、无结果、错误、过期数据和部分删除失败均有明确反馈。
- 三种窗口宽度下不存在遮挡或无法访问的主要操作。
